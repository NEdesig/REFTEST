
# REFTEST

Мобильное веб-приложение для подготовки хоккейных арбитров.

## Технологии

- React
- Vite
- Supabase Auth
- Supabase PostgreSQL
- GitHub Pages

## Запуск локально

1. Установить Node.js.
2. Выполнить `npm install`.
3. Создать `.env.local` с настройками Supabase.
4. Выполнить `npm run dev`.

## Сборка

`npm run build`

## Публикация

Настроить GitHub Pages для сборки Vite через GitHub Actions.

## Важно

До публичного запуска необходимо реализовать серверную проверку
ответов, запись результатов и серверное ограничение частоты тестов.
Правильные ответы нельзя передавать клиенту до завершения теста.
